One short poem about agency — the power to ask and to be given — written out by a small,
deterministic Python program. The poem lives in the source, verbatim, as `POEM` in `main.py`;
running the program writes those 277 characters to `/output/entry.txt` and nothing else.

The poem:

> Power of Attorney
>
> She practiced her name on a receipt,
> pencil, then ink,
> then signed the page
> that sells her house.
> She looked up like a girl
> done with a hard test
>
> Each morning she asks
> if she may have her pills.
> I say yes. I say it
> as though the yes were still
> hers to give.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

Python 3.13, standard library only, no network, no input, no randomness: the same bytes on every run.
